ITALIANO

L'IDEA IN UNA RIGA

   Il programma sta sulle postazioni. L'inventario sta sulla
   cartella di rete. Uno solo, per tutti.

   L'inventario deve essere uno: se ogni tecnico ne tenesse una
   copia, dopo mezza giornata sarebbero tutte diverse e nessuna
   vera. Il programma invece e' lo stesso codice su ogni PC, non
   c'e' niente da condividere.


1) PREPARA UNA COPIA, UNA VOLTA SOLA

   Su un PC qualsiasi:

   a) estrai questo pacchetto in una cartella LOCALE, per esempio
      C:\Inventario     (non sulla cartella di rete);

   b) doppio clic su  "Collega inventario condiviso.bat";

   c) incolla il percorso della cartella di rete, per esempio
         \\server\Condivisa\Inventario

   Se sulla rete l'inventario non c'e' ancora viene creato vuoto,
   in Produzione\Inventario.xlsx. Se c'e' gia', non viene toccato.

   Serve il permesso di MODIFICA su quella cartella di rete.


2) PORTA L'INVENTARIO CHE HAI GIA'

   Se un inventario esiste gia', copialo sulla rete con il nome
   giusto e nel posto giusto:

      \\server\Condivisa\Inventario\Produzione\Inventario.xlsx

   Il nome dev'essere esattamente Inventario.xlsx, dentro la
   cartella Produzione. Chiudi il programma prima di sostituirlo, e
   tieni una copia del file vecchio finche' non hai verificato che
   l'inventario si apra e i dispositivi ci siano tutti.

   ATTENZIONE: un foglio Excel DA IMPORTARE - con altre colonne, o
   diviso per stanze con le righe separatore - NON va copiato li'.
   Quello si carica da dentro il programma, con  Importa xls...


3) DISTRIBUISCI LA CARTELLA ALLE POSTAZIONI

   La cartella che hai preparato e' gia' configurata: la
   configurazione viaggia con lei. Copiala tale e quale su ogni
   postazione, sempre nello stesso percorso locale.

   Su ogni postazione, doppio clic su
   "Crea collegamento sul desktop.bat": mette l'icona sulla
   scrivania dell'utente.

   Da li' in poi si apre con doppio clic sull'icona.


AGGIORNARE IL PROGRAMMA PIU' AVANTI

   Scarica il pacchetto nuovo e sostituisci la cartella locale del
   programma su ogni postazione. NON toccare
   inventario_percorso.json: e' la riga che dice dove sta
   l'inventario condiviso. Se lo sovrascrivi, ripassa
   "Collega inventario condiviso.bat".

   I dati non si toccano mai: stanno sulla rete.


SE QUALCOSA NON TORNA

   Doppio clic su  "Diagnostica.bat".  Scrive Diagnostica.txt qui
   accanto e te lo apre: dentro c'e' la versione in uso, quale
   inventario apre, se puo' scriverci, e cosa legge dai file Excel.
   Non modifica niente. Mandalo a chi ti assiste.

   La versione in uso e' scritta anche nella barra del titolo
   della finestra.

ENGLISH

THE IDEA IN ONE LINE

   The program goes on the workstations. The inventory goes on the
   network folder. One inventory, for everybody.

   The inventory has to be one: if every technician kept a copy,
   after half a day they would all differ and none would be true.
   The program is the same code on every PC, with nothing to share.


1) PREPARE ONE COPY, ONCE

   On any PC:

   a) extract this package into a LOCAL folder, for example
      C:\Inventario     (not onto the network folder);

   b) double-click  "Collega inventario condiviso.bat"
      (link shared inventory);

   c) paste the path of the network folder, for example
         \\server\Shared\Inventory

   If the inventory is not on the network yet, an empty one is
   created at Produzione\Inventario.xlsx. If it is there already,
   it is left alone.

   You need MODIFY permission on that network folder.


2) BRING THE INVENTORY YOU ALREADY HAVE

   If an inventory already exists, copy it onto the network with
   the right name in the right place:

      \\server\Shared\Inventory\Produzione\Inventario.xlsx

   The name must be exactly Inventario.xlsx, inside the Produzione
   folder. Close the program before replacing it, and keep a copy
   of the old file until you have checked that the inventory opens
   and every device is there.

   CAREFUL: an Excel sheet TO IMPORT - with other columns, or split
   by room with separator rows - must NOT be copied there. That one
   is loaded from inside the program, with  Import xls...


3) HAND THE FOLDER OUT TO THE WORKSTATIONS

   The folder you prepared is already configured: the configuration
   travels with it. Copy it as it is onto every workstation, always
   to the same local path.

   On each workstation, double-click
   "Crea collegamento sul desktop.bat": it puts the icon on the
   user's desktop.

   From then on it opens with a double-click on the icon.


UPDATING THE PROGRAM LATER

   Download the new package and replace the local program folder on
   each workstation. Do NOT touch inventario_percorso.json: that is
   the line saying where the shared inventory is. If you overwrite
   it, run "Collega inventario condiviso.bat" again.

   The data is never touched: it lives on the network.


IF SOMETHING IS OFF

   Double-click  "Diagnostica.bat".  It writes Diagnostica.txt
   beside it and opens it: inside are the version in use, which
   inventory it opens, whether it can write there, and what it
   reads from Excel files. It changes nothing. Send it to whoever
   helps you.

   The version in use is also written in the window title bar.
